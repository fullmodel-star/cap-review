# 704 會考複習

國中教育會考 105–114 年五科（國文、英語閱讀、數學、社會、自然）歷屆選擇題的複習 PWA，給準備會考的國三學生自學用。單一使用者、免登入、進度存在瀏覽器 IndexedDB。

- 題目來源：國中教育會考官方公告歷屆試題（心測中心 cap.rcpet.edu.tw），原始 PDF 在 `Desktop\國中教育會考_歷屆試題_110-114\`（資料夾名稱沒改，實際是 105–114 年）
- 不含：英語聽力（音檔，另一種工程）、寫作測驗改成筆記分頁的「作文題目」參考，不做測驗

## 功能

| 分頁 | 內容 |
|---|---|
| 📖 筆記 | 五科常考觀念，依 10 年出現次數排序，每個觀念可直接「練這個觀念」；另有歷年作文題目 |
| ✏️ 練習 | 科目／年份／觀念篩選；選單一年份＋單一科目時照題號順序（像寫一份考卷），其他隨機 |
| 🔁 錯題複習 | 今日到期／所有錯題／頑固題；間隔重現＋連對 3 次畢業（沿用 701 錯題管理器的 `grade()` 邏輯） |

出題卡以**原題圖**為主（從官方 PDF 逐題裁切），題組題上方附**題組文章圖**；答完顯示解析、「看原頁」、文字版（有已知轉寫錯誤的題目不顯示文字版）。

## 目錄

```
index.html  sw.js  manifest.json            ← 前端（單檔，無 build）
data/questionbank_<科>.json                  ← 題庫（題目、官方答案、觀念、圖路徑、解析）
data/concept_notes_<科>.json                 ← 觀念筆記
data/answers_<年>.json                       ← 官方答案（105–110 為讀圖重抽，見下方）
data/images_<科>.json  data/writing.json     ← 圖片對應、作文題目
assets/q  assets/g  assets/page  assets/writing   ← 原題圖、題組文章圖、整頁圖、作文頁
_pipeline/                                   ← 資料管線（不部署）
img/  _pipeline/extracted/                   ← 管線中間檔（gitignore）
```

## 資料管線（順序）

1. `render_pages.py <年> <科>`：PDF → 頁面 PNG（給抽題 agent 讀圖）
2. 抽題：每科每年一個 agent 用 Read 讀頁面圖，寫 `_pipeline/extracted/<年>_<科>.json`
3. `parse_answers.py <年>`：官方答案 PDF → `data/answers_<年>.json`
4. `merge_subject.py <科>`：抽題＋答案 → `data/questionbank_<科>.json`（**重跑會保留 concept_tag／解析／圖等後加欄位**）
5. 觀念歸納：每科一個 agent 標 `concept_tag` 並寫 concept_notes
6. `crop_questions.py`：依 PDF 文字層座標逐題裁原題圖、題組文章圖、整頁圖
7. 解析：每科每年一個 agent 看原題圖、朝官方答案寫解析（任務說明 `_pipeline/review_prompt.md`，輸出 `_pipeline/review/<年>_<科>.json`）
8. `apply_extras.py`：把圖片對應與解析併回題庫（可重跑）
9. `build_writing.py`：寫作測驗題目頁

## ⚠️ 踩過的雷（改資料前必讀）

- **105–110 年官方答案 PDF 的表格，pdfplumber 會切錯欄位**（自然／社會／數學互相錯位，例如 105 年數學被算成 55 題）。這六年的答案改用讀圖重抽，並用已知題數（英聽 21、社會 63、自然 54）逐年驗證。`parse_answers.py` 只對 111–114 可信，**不要再用它重產 105–110**。解析階段每題再驗算一次，五科 flag 皆 0。
- **國文抽題會被內容過濾器中斷**：要求「逐字轉錄古文」本身會觸發，改成「可用自己的話改寫」並逐頁處理即可。因此國文部分 `question_text` 是改寫，**以原題圖為準**。
- **轉寫文字對圖的描述常有錯**（自然尤其多，箭頭方向、正負電荷、選項圖描述），標在 `text_issue`。前端一律以原題圖為主。
- **裁切的大題標頭判斷**必須同時帶「單題／題組／選擇題／部分」，否則「一、二年級的…」這種題目文字會被誤判成標頭而把題目切斷。
- **重裁圖片時不要先刪 `assets/`**：解析 agent 在讀圖，會讀到空檔。直接覆寫即可。
- 平行 agent 共用 scratchpad，暫存檔要加 `<年>_<科>_` 前綴，否則會互相覆蓋（實際發生過一次）。
- `sw.js`：頁面與 `data/` 走 network-first（修正題目才會送到手機），圖片 cache-first；改前端或資料記得升 `CACHE` 版號。

## 年級標註

- 數學：依 108 課綱學習內容代碼（代碼中間數字＝年級），代碼皆與官方 PDF 核對
- 自然：課綱只標第四學習階段；依分科（生物七、理化八九、地科九），理化細分八或九年級為常見教材順序，把握不足者維持「八、九年級」
- 國文、英語、社會：官方課綱不分年級，未標
- 課次（第幾課）：各出版社不同，需知道學校用哪一版並取得目錄才能做，目前未做
